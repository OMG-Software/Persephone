# Desktop UI host guidance

This area inherits `../AGENTS.md` and implements ADR-0004.

- Keep this process keyless. Relay approved commands to the core through `src/core_link.rs`. Do not add SDK clients, credentials, keys, stores, or media-broker authority here.
- Keep launch and inherited-pipe ownership checks. Start the application through the core binary, `persephone`; `persephone-ui` requires its core channel.
- When adding a command, update its Rust handler, `build.rs` registration, `capabilities/main.json`, the frontend bridge, core protocol/handler, and IPC tests together. Review the minimum permission required.
- `permissions/autogenerated/` and ignored `gen/` schemas come from `tauri-build`. Change command registration and rebuild rather than hand-editing generated permissions.
- Preserve local-origin checks, invoke-key checks, the explicit command allowlist, restrictive CSP, disabled new windows, and blocked external navigation. Do not enable generic plugins, dynamic permissions, payload tracing, or broader dependency features without review.
- Treat page arguments as untrusted. Check bounds before relaying, and keep validation at the core boundary too. Tauri handler checks cannot bound allocations made before the handler runs.
- Fail the transport for all waiting callers on malformed replies, unknown reply IDs, or broken pipes. Preserve bounded framing and whole-frame writes when replies and events share a pipe.
- Keep room notifications content-free and subscriptions bounded. Store page channels only after core acceptance, and clear subscriptions on page load. Keep errors sent to the page generic and free of internal paths or payloads.
- Preserve `windows-app-manifest.xml` embedding for MSVC test artifacts as well as the application. Do not remove the manifest workaround without checking test executable startup.
- Build the frontend first with `python tools/dev.py frontend`. Then run `cargo test --locked -p persephone-desktop`, including `tests/ipc.rs`. Use `python tools/dev.py rust` for the complete Rust build order and checks.
- Mock-runtime IPC tests do not prove packaged web-view containment. Record real runtime, memory-flood, and platform checks separately when the boundary changes.
