# Research guidance

This area inherits `../AGENTS.md`.

- Treat these files as dated research inputs. Accepted ADRs govern the chosen design. Preserve earlier comparisons as history rather than presenting them as current decisions.
- Prefer primary sources. Record exact versions, feature sets, source locations, and the date checked. Recheck moving upstream facts when using them for a new decision.
- Distinguish source inspection, dependency analysis, executed experiments, and inference. State methods and limitations for security comparisons.
- Do not rank frameworks as inherently secure or equate memory-safe code with OS containment. Review actual parser, IPC, dependency, accessibility, and platform behavior.
- Keep archives attributable and sanitized. Explain source and purpose when adding or replacing binary evidence; do not modify an evidence archive incidentally.
